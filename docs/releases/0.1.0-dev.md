## Limitations and migration risks

- Ordinary Compact is not canonical CBOR and does not sort keys.
- Tags are raw syntax only and carry no schema or Wire identity.
- CBOR syntax depth is independent of Serde logical depth, item budgets, and path tracking.
- Inline UTF-8 carry owns at most one scalar; borrowed ranges require the exact unchanged producing input actual.
- The allocating facade may raise `Storage_Error` after entering Failed; completed output copying is retryable.
- Serde must privately translate syntax events/errors and retain all logical envelopes, policies, construction, and
  transactional candidate behavior. Typed values continue to reject leading tags while Skip may consume them.
- The full multi-platform CI matrix has not run on a public host, and no indexed reproduction can exist before an
  explicitly authorized index entry. These are publication gates, not claims of this local candidate.
